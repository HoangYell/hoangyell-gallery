# Changelog

## 1.0.0 — 2026-05-24

Initial release.

- Astro `<Gallery />` component with pyramid multi-row layout
- Accessible lightbox (keyboard, swipe, focus restore)
- Four-corner rounding on gallery groups (no wrapper background)
- Hover zoom contained inside each cell
- CSS custom properties for theming
- `prefers-reduced-motion` support
